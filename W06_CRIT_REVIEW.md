# Portfolio Critique — Review Checkpoint

## Proof statement

> I build practical AI systems from data to deployment, with the engineering underneath them.

## Reviewer feedback

The portfolio was reviewed against the proof statement. The first-impression questions were:

1. **In ten seconds, what do I do?**
   - The strongest impression was that I work across software/engineering and practical AI rather than only visual design.
   - The reviewer could understand that the portfolio is intended to present technical work and engineering capability.

2. **Would you believe I'm good at it?**
   - The work shows technical ability, but the first screen did not make the AI/engineering positioning as clear as it could be.
   - The portfolio had enough evidence to create interest, but the message needed to be more direct and the calls to action needed to feel more purposeful.

### Additional feedback

- The old hero positioning was too design-focused and could confuse a visitor about the actual role.
- The portfolio should lead with AI/engineering work and explain the value in plain language.
- Contact should remain easy to find.
- Mobile interaction and readability should be treated as first-class requirements.
- Decorative effects should not compete with the work.
- Placeholder or unclear links reduce trust.

## Sorting the feedback

### Must-fix

1. **Role positioning was confusing.** The hero said "Lead Graphic Designer", which conflicts with the proof statement and can make the visitor classify the portfolio as a design portfolio.
2. **The first-screen message did not clearly communicate practical AI/engineering.** This hurts the main action: understanding what I do.
3. **A placeholder LinkedIn link existed.** A dead social link is a visible trust problem.
4. **The CV button had no real destination.** A button labelled Download CV without a downloadable file is misleading.
5. **Mobile behavior needed hardening.** Tap targets, responsive spacing, and expensive interactions needed explicit mobile handling.

### Nice-to-have

1. More case-study detail for each project.
2. Testimonials.
3. More social proof and metrics.
4. A more advanced project filtering system.
5. Further visual polish after the core message is clear.

## What I changed

- Reworked the hero positioning so the portfolio presents practical AI/software engineering rather than only graphic design.
- Made the primary message more direct and evidence-oriented.
- Kept the project and contact paths prominent.
- Replaced the LinkedIn placeholder with the actual profile destination.
- Replaced the dead CV download control with an explicit CV request action.
- Hardened mobile layout, tap targets, image containment, keyboard focus, and reduced-motion behavior.
- Disabled heavy particle/tilt interactions on touch devices and deferred below-the-fold images.
- Removed an unused 16.7 MB image asset.

I treated the review as a usability and trust check rather than defending the original design. I prioritized anything that could confuse the visitor about my role, weaken trust, or make the main action harder, and left cosmetic improvements for later.
